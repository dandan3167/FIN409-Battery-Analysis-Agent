# Third-party sources and rights

The evidence directory contains company annual reports, government documents, institutional research, third-party reporting and archived source extracts/images. Their original organisations, locators and known dates are retained in the evidence records and manifest. No required source asset has been excluded or altered for size reduction.

This package does not assign an open-source licence to these reports or source materials, nor claim ownership of them. Public availability does not itself grant unrestricted redistribution rights. Copyright, attribution, data-use terms and any source-specific licence remain with the relevant rights holders. Source availability and metadata are not independent permission verification.

Before any future public upload, confirm that redistribution of the bundled third-party material is permitted for the intended submission. A private assessment repository may have different access conditions, but the user must still verify the applicable rights. This package has not been uploaded or published.

No required asset is currently missing. If transferring separately, obtain the exact assets from the retained curated evidence directory using the manifest paths and verify SHA-256 hashes. The source URLs are attribution/finding aids; a later web download may differ from the preserved version and must not silently replace an immutable asset. No automatic retrieval script is included.
