# Completed English report example — not a formal input

This folder contains one completed English report, its reader references and its original claim-source mapping. It illustrates output and citation structure for human review. It is not a required answer, training target or source of facts for fresh analysis. Do not read it during a fresh model run.

The report is the final report's Markdown body after limited repetition trimming; the mapping and references come from the approved editorial version. All C001–C031 claims, evidence links and findings remain consistent. This is a single example, not a second run or multiple historical drafts. It is not a complete sealed-run reproduction; that would also require the run's model analysis, review and manifests, deliberately excluded here.

Source paths in the JSON mapping resolve from the package root, not this subdirectory. R01-style reference links resolve within references_en.md. The example report's C001-style labels map to claim_source_map.json and the claim index in references_en.md. The example is never loaded by the formal configuration or CLI.
